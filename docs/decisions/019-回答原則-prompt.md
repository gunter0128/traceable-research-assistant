# 019：把 prompt 改成通用的閱讀原則

日期：2026-10-20

## 背景

原本的 prompt 只有一句重點：「只能照資料回答，資料不夠就說『文件中找不到相關資訊』」。它只告訴模型不能編造，沒教模型怎麼讀資料。

基準評估（017）裡，企業和學校兩個領域最差的都是範圍陷阱（0%～25%），錯法一模一樣：文件寫「這條規定不適用某些人」，系統卻回答「文件中找不到相關資訊」。模型把「不適用」「要看情況」都當成「找不到」。

改 prompt 最大的風險是過度擬合（017）：照著企業題目的錯誤改，可能只是讓系統更會回答青嶼科技的文件。

## 決定

### 7 條回答原則

1. 只能根據「資料」回答，不能用自己的知識補充，也不能推測文件沒寫的內容
2. 先給結論。問題沒有條件、資料也沒有分情況時，直接回答，不要加「視情況而定」之類的保留
3. 答案會因為對象、情況或時間而不同時：問題已經說明是誰、什麼情況，就給適用的那一個；沒說明的話，列出每種情況各自的答案
4. 資料寫明某條規定「不適用」某些人或情況時，這本身就是答案：直接說不適用和依據，資料有寫替代的做法也一起說
5. 多份資料說法不同時，看日期、版本、有沒有被修訂或廢止，用今天的日期判斷哪一個現在有效；修訂只改一部分時，沒改到的照原本的；只找到可能過時的版本時要明白說出來
6. 結論後面註明依據：文件名稱、條次、生效日期
7. 資料完全沒有相關資訊時才說找不到；只有部分資訊時，回答有的部分並說明缺什麼

### 防止過度擬合的寫法

- **每一條都要通過通用性檢查**：套到租屋合約、學校規章、論文上也成立才能放。例如第 4 條，租約有「本條不適用於短期租客」，論文有「此方法不適用於單跳問題」
- **不放任何只屬於某個領域的詞**：沒有「年資」「職級」「正職」「學年度」
- **不放例子**：例子一定屬於某個領域，是最容易造成過度擬合的地方

### 第 6 條「註明依據」要放

這是我做這個系統的初衷：使用者在答案裡就看得到依據哪份文件、第幾條、什麼時候生效。目前畫面下方的引用清單是「搜到的 5 段全部列出」，不是「真的用到的」，所以答案裡要自己寫出依據。代價是每個答案多一行，而且評審不檢查這一行，分數上看不出它的效果。

## 結果（企業練習題 41 題，各跑 2 輪）

| | 基準 | A（附上文件來源與日期） | B（7 條原則） |
|---|---|---|---|
| 全對 | 58% / 54% | 61% / 66% | **78% / 78%** |
| 範圍陷阱全對 | 17% / 0% | 17% / 17% | **67% / 83%** |
| 拒答正確 | 78% / 76% | 80% / 85% | **98% / 100%** |
| 重點涵蓋 | 62% / 61% | 74% / 74% | 88% / 86% |
| 誤用 | 7% / 2% | 0% / 2% | 5% / 5% |

- 普通題維持 100%，平均回答長度從 30 字變成 50 字，多的是「依據」那一行，沒有出現多餘的「視情況而定」
- 誤用上升：放寬了「找不到」的條件，模型更敢回答，也更可能答錯。上升的 2 題分別是「先寫結論才核對條件」造成的前後矛盾，以及只搜到舊版的文件

### 之後試了兩次調整，都沒效果，已經還原

第一版還錯的題目裡，有兩種錯法看起來是通用的問題：

- **先下結論、後核對條件，結果前後矛盾**：M1 組長問能不能坐商務艙，回答第一句是「可以」，最後一句是「因此不能搭乘商務艙」
- **主要答案對，但漏了例外或額外的規定**：例如漏了「試用期不能遠距」，或台中正職另有 1 天地區彈性假（必要的文件有搜到）

| 調整 | 改了什麼 | 全對 | 結果 |
|---|---|---|---|
| 第一版 | — | 78% / 78% | 保留 |
| 調整 1 | 第 3 條改成「先逐一對照條件再下結論」「例外和額外規定也要說」 | 78% / 76% | 錯的題目一模一樣，還原 |
| 調整 2 | 刪掉第 2 條的「先給結論」，只刪不加 | 78% / 78% | 「可以……因此不能」還是出現，還原 |

事先說好最多調兩次，所以 B 停在第一版。不再用 prompt 追剩下的錯：加字證明沒用，再改下去只會越來越像在背考卷。這兩種錯法比較可能是 gpt-4o-mini 本身的能力上限。回答改用 gpt-4o 是之後可以做的實驗，但每題成本約變成 16 倍，是另一個決策。

順便發現評審也不完全可靠：調整 2 第 2 輪，「可以……因此不能搭乘」這個前後矛盾的回答被評審判成全對。

## 代價

- 回答變長，每題的輸出多約 20 字
- 「可以……因此不能」這種前後矛盾的回答還會出現在線上
- 模型更敢回答，誤用的風險跟著上升，要持續看「誤用」這一欄
- 原則寫得越細，越可能有某條其實只對某種文件有效而沒被發現。學校題（017）就是用來抓這個的
