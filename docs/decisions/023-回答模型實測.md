# 023：回答模型 gpt-4o-mini 和 gpt-4o 的實測比較

日期：2026-10-20

> 這份是 Claude 在我睡覺時量的。**換不換模型還沒決定**：換了每題成本會變成約 16 倍，由我看完再決定。

## 背景

改完 prompt（019）之後，剩下的錯有一部分看起來是模型本身的能力限制：

- 「可以……因此不能搭乘商務艙」這種前後矛盾的回答
- 資料一多就混淆（020）
- 約 12% 的答案忘了標引用編號（021）

002 當初決定「回答用的模型以後可以換，用評估比較品質和成本」，所以這次量一次。

## 怎麼量

評估程式加了 `--model` 參數，同樣的程式、同樣的 prompt，只換回答用的模型，三套題目各跑 2 輪：

| 題目 | gpt-4o-mini（現在） | gpt-4o |
|---|---|---|
| 企業練習題（41 題） | 76% / 73% | 80% / 80% |
| 企業考試題（17 題，沒看過） | 76% / 65% | 76% / 82% |
| 學校（21 題，別的領域） | 86% / 90% | 95% / 95% |
| 答案有標引用編號（練習題） | 88% | 100% |

- 三套題目都是 gpt-4o 比較好，平均高約 6～9%，沒看過的考試題和學校題也一樣，不是只在練習題上好
- 誤用沒有明顯差別。學校題 gpt-4o 是 0%，mini 是 5%；企業題兩者差不多
- 前後矛盾沒有完全消失：M1 組長那題，gpt-4o 第 1 輪還是答錯
- 回答速度差不多（本機量的平均約 1.7 秒）

## 成本

用實際的用量算（同樣的題目、同樣的 token 數）：

| | 每題 | 每天 10 題，一個月 | 每天 50 題，一個月 |
|---|---|---|---|
| gpt-4o-mini | 約 0.00044 美元 | 約 0.13 美元 | 約 0.66 美元 |
| gpt-4o | 約 0.0073 美元 | 約 2.2 美元 | 約 11 美元 |

每天的用量上限（012）也要一起看：每人每天 0.5 美元，換成 gpt-4o 後，大約只夠問 **68 題**（mini 約 1,100 題）；全系統每天 5 美元，約 680 題。

## 選項

| 選項 | 說明 |
|---|---|
| ① 維持 gpt-4o-mini | 最便宜，品質差 6～9% |
| ② 回答改用 gpt-4o | 品質最好、引用標得最完整。以現在的使用量（我和幾位同學），一個月約 2～5 美元。每人每天約 68 題，對一般使用夠用 |
| ③ 讓使用者自己選（roadmap B5 原本的想法） | 最有彈性，但要做選單、記錄每題用哪個模型、成本和上限也要分開算，要多半天到一天 |

**Claude 的建議：②。** 這個系統要解決的就是「答案能不能信任」，6～9% 的差距大多落在條件、例外、版本這些最容易誤導人的題目。以目前的使用量，成本增加在可以接受的範圍。要換的話只要改一行（`GENERATION_MODEL`），再在價目表補上 gpt-4o 的價格。
