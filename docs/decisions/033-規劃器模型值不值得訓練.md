# 033：規劃器模型值不值得訓練（不值得，先不做）

日期：2026-10-24

## 背景

MLOps 的候選方向是：訓練一個小模型取代 gpt-4o-mini 規劃器，專門判斷「這題要去哪幾份文件找」（028 的 catalog 規劃器；也是我論文的未來工作「可學習的規劃器」）。

之前在調整前的練習題上量過「完美的規劃器」的上限，比不規劃多 7～14 分（031）。但上限是假設選文件百分之百正確，訓練出來的模型不會這麼準。投入之前，要先回答：**模型要準到幾成，才換得到分數？**

## 怎麼量

新的 70 題（練習題 + 考試題全部），找 5 段、固定長度切段，每組 2 輪：

| 組別 | 做法 |
|---|---|
| 不規劃 | 線上現在的做法，基準 |
| 完美的規劃器 | 直接照題目的標準出處，去每一份該用的文件裡搜（`eval/run.py --planner oracle`） |
| 選對 80% 的規劃器 | 全部題目該用的文件合起來剛好拿掉 20%，每題另外多選 1 份不相關的文件（`--oracle-recall 0.8 --oracle-wrong 1`）。80% 是因為 gpt-4o-mini 規劃器大約就是這個準度 |
| gpt-4o-mini 規劃器 | 028 的 catalog，真實的參考點 |

**判斷標準在看結果之前先寫好**（早上報告裡有時間紀錄）：完美規劃器比基準平均多 8 分以上，**而且**選對 80% 還能多 4 分以上，才值得做。

## 結果

指標的意思：

- **全對**：重點全提到、沒說錯、該拒答的有拒答
- **檢索完整**：該用的文件全部找到才算（勞動法規的文件很長，這個指標會高估，另外附「依據的原文全部找到」：每題附的條文原文每一段都找到才算，這個偏嚴）

| | 青嶼科技 70 題 | | 勞動法規 70 題 | | |
|---|---|---|---|---|---|
| | 全對 | 檢索完整 | 全對 | 檢索完整 | 原文全部找到 |
| 不規劃 | 73% / 74% | 78% | 63% / 70% | 80% | 42% |
| 完美的規劃器 | 87% / 86% | 100% | 73% / 73% | 100% | 57% |
| 選對 80% 的規劃器 | 76% / 73% | 88% | 70% / 69% | 98% | 50% |
| gpt-4o-mini 規劃器 | 79% / 81% | 85% | 60% / 61% | 78% | 36% |

澄溪國小（21 題，煙霧測試）：不規劃 76% / 76%，完美的規劃器 90% / 86%。

| 全對（2 輪平均） | 兩套平均 | 比基準多 |
|---|---|---|
| 不規劃 | 70.0% | — |
| 完美的規劃器 | 79.8% | +9.8 |
| 選對 80% 的規劃器 | 72.0% | +2.0 |
| gpt-4o-mini 規劃器 | 70.3% | +0.3 |

**照事先訂的標準：上限有（+9.8），但選對 80% 只剩 +2.0，不值得做。**

## 看得出來的事

1. **好處幾乎都集中在「全部選對」**。從 100% 降到 80%，青嶼科技從 +13 分掉到 +1 分。一題常常要合起來看兩份文件，少選一份，答案就不完整；多選的不相關文件也會佔掉名額。模型要做到接近完美才有用，這是很高的門檻
2. **真實的 gpt-4o-mini 規劃器在兩套上方向相反**：短文件的青嶼科技 +6.5 分，長文件的勞動法規 −6 分。長文件上，「去哪份法規找」對了，在那部法規裡找到的條文卻常常不對（原文全部找到從 42% 掉到 36%）
3. **就算選文件完全正確，答錯的主因還是「找到了還答錯」**：完美規劃器時，青嶼科技每輪 9～10 題、勞動法規每輪 18 題答錯，幾乎全都是找到了還答錯

## 決定

- **不訓練規劃器模型**。投入訓練資料、訓練、部署之後，模型要接近完美才換得到分數；接近 80% 的準度只會多 2 分左右
- 線上維持不規劃。規劃器和模擬的程式留著當評估工具
- 下一個方向另外決定（見代價和早上報告的選項）

## 代價

- 「選對 80%」是模擬的：隨機拿掉文件、隨機多選一份。真實的規劃器犯的錯比較「聰明」：gpt-4o-mini 規劃器在青嶼科技上準度只有 85%，卻比模擬的 88% 多拿了 5 分。所以模擬可能**低估**了不完美規劃器的價值，但勞動法規上真實的規劃器反而變差，也看不出模擬是高估還是低估
- 只模擬了一種準度（80%），沒有量出完整的曲線
- 判斷標準的 8 分、4 分是我事先訂的經驗值，不是從統計推出來的
- 每組只跑 2 輪；兩套合計 140 題、2 輪平均，粗估的隨機誤差約 ±3 分
